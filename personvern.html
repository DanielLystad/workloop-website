1. Innledning

Wollan-Frantzen Trading Company, som driver WorkLoop («vi», «oss», «vår»), er opptatt av å beskytte ditt personvern. Denne personvernerklæringen forklarer hvordan vi behandler personopplysninger i forbindelse med Nettsiden workloop.no («Nettsiden»).

Denne erklæringen er utarbeidet i samsvar med EUs personvernforordning (GDPR) og den norske personopplysningsloven.

Vi etterstreber at alle brukere skal kunne lese og forstå denne erklæringen uavhengig av funksjonsevne. Informasjon om vårt arbeid med universell utforming og tilgjengelighet finner du i bruksvilkårene §11. Ønsker du erklæringen i et alternativt format, ta kontakt på kontakt@workloop.no.

3. Hvilke personopplysninger behandles?

Nettsiden er en ren informasjonsside uten kontaktskjema, brukerregistrering eller innlogging. Vi samler derfor inn svært lite data.

3.1 E-postkommunikasjon

Nettsiden oppgir vår e-postadresse (kontakt@workloop.no) slik at du kan kontakte oss direkte. Dersom du velger å sende oss en e-post, mottar vi opplysningene du selv inkluderer — typisk navn, e-postadresse og innholdet i meldingen. Denne kommunikasjonen går via din egen e-postklient og våre e-postsystemer, ikke via Nettsiden.

3.2 Tekniske data (hostingleverandør)

Nettsiden er hostet på GitHub Pages. GitHub kan automatisk logge visse tekniske opplysninger i forbindelse med levering av nettsiden, som IP-adresse, nettlesertype, tidspunkt for forespørsel og forespurt URL. Workloop har ikke direkte tilgang til eller kontroll over disse loggene. For mer informasjon, se GitHubs retningslinjer for Pages.

Vi samler ikke inn personopplysninger direkte via Nettsiden. Vi benytter ingen sporingsverktøy, analysetjenester, kontaktskjema eller innloggingsfunksjoner.

4. Informasjonskapsler (cookies)

Nettsiden benytter ingen informasjonskapsler (cookies). Vi bruker ingen analyse-, markedsførings- eller tredjepartscookies. Det er ingen cookie-banner fordi det ikke settes noen cookies.

5. Formål og rettslig grunnlag

De begrensede personopplysningene som kan behandles har følgende formål og rettslige grunnlag:

Formål Rettslig grunnlag (GDPR)
Besvare henvendelser sendt til oss per e-post Art. 6(1)(b) — nødvendig for å gjennomføre tiltak på den registrertes anmodning, eller Art. 6(1)(f) — berettiget interesse
Levering av Nettsiden (tekniske logger via GitHub Pages) Art. 6(1)(f) — berettiget interesse i å sikre tjenestens funksjonalitet

6. Deling av personopplysninger

Vi selger aldri dine personopplysninger til tredjeparter.

Nettsiden hostes på GitHub Pages (GitHub, Inc.), som er en del av Microsoft Corporation. GitHub kan behandle visse tekniske data i forbindelse med hosting av Nettsiden. GitHub opererer under EUs standardkontraktsklausuler (SCC) og Microsofts databehandleravtale.

Vi kan utlevere opplysninger dersom vi er rettslig forpliktet til det, for eksempel ved pålegg fra norske myndigheter.

7. Overføring til tredjeland

GitHub Pages-infrastrukturen kan innebære behandling av data utenfor EU/EØS (USA). Denne overføringen er basert på EUs standardkontraktsklausuler (SCC) og EUs adekvathetsbeslutning for USA (EU-US Data Privacy Framework), i samsvar med GDPR kapittel V.

8. Lagring og sletting

E-postkorrespondanse slettes som hovedregel innen 12 måneder etter at henvendelsen er besvart og saken avsluttet, med mindre lengre lagring er påkrevd ved lov. Tekniske logger hos GitHub administreres i henhold til GitHubs egne retningslinjer.

9. Dine rettigheter

I henhold til GDPR og personopplysningsloven har du følgende rettigheter:

Rett til innsyn — Du kan be om informasjon om hvilke personopplysninger vi eventuelt har om deg (art. 15).

Rett til retting — Du kan be om at uriktige opplysninger korrigeres (art. 16).

Rett til sletting — Du kan be om at vi sletter dine personopplysninger når det ikke lenger er et gyldig grunnlag for behandlingen (art. 17).

Rett til begrensning — Du kan be om at behandlingen av dine opplysninger begrenses i visse tilfeller (art. 18).

Rett til dataportabilitet — Du kan be om å motta dine opplysninger i et strukturert, maskinlesbart format (art. 20).

Rett til å protestere — Du kan protestere mot behandling basert på berettiget interesse (art. 21).

For å utøve dine rettigheter, ta kontakt med oss på kontakt@workloop.no. Vi vil besvare henvendelsen din innen 30 dager.

10. Sikkerhet

Nettsiden serveres over kryptert tilkobling (HTTPS). Vi har ingen brukerkontoer, databaser eller lagringsmekanismer på Nettsiden. E-postkommunikasjon beskyttes av våre e-postsystemers sikkerhetstiltak.
